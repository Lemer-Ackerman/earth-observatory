# ~~这是个音乐播放器~~ 三维地球观测台

三维地球档案观测台 - WebGL 交互单页
3D Earth Archive Observatory - WebGL Interactive Single Page

一个跑在浏览器里的三维地球仪表盘：真实地表影像、可拖拽自转、板块档案、太阳光照，
以及一段"转够快就播"的音乐。

## 功能

**地球**
- Esri 真实地表影像 + 大气辉光 + 夜面城市灯光
- 东西向自转，南北极固定；拖动球体可加速，遥测面板实时显示 `s/圈`
- 自转达到 **1 秒/圈**时播放 BGM，松开即暂停，再转从暂停处续播
- 右上角「恒转」按钮：以 1.6s/圈 匀速自转并播完整首曲目
- 点大陆 → 板块边界红线顺时针描绘 + 大洲档案；点海洋 → 地球档案

**太阳系**
- 太阳光照（5778K 色温、1/r² 辐照度、反照率）与开普勒公转
- 8 颗行星 + 月球（潮汐锁定、5.1° 轨道倾角）；金星逆行、天王星躺转
- 远景拉出太阳系列表，点条目可聚焦

**档案**
- 12 本书脊档案：宇宙周边环境 / 四大洋 / 七大洲
- 气候索引、生物卡（72 张真实动物图）、矿物与温度规格

**其他**
- 传感器滤镜：标准 / 夜视 NVG / 热成像 FLIR / Noir（`1`–`4` 切换）
- 遥测面板：公转周期、自转档位、当前自转速度、相对日照、视点高度

## 交互速查

| 操作 | 效果 |
|---|---|
| 拖动地球 | 东西向自转（南北极固定） |
| 点击地球 | 聚焦并打开档案 |
| 滚轮 | 拉近拉远 |
| 点击书脊 | 抽出档案书 |
| `1` `2` `3` `4` | 切换传感器滤镜 |
| `B` | 风声 BGM 开关 |
| `W` | 恒定自转 + 播完整曲 |

## 自选音乐

点开**地球档案**，底部有「自转音频 / SPIN AUDIO」区块：

- **更换音乐** — 选择本地音频文件（mp3 / wav / m4a / ogg）
- **恢复默认** — 换回内置曲目《突然的陀螺》

换了曲目后，触发播放的规则不变（还是自转够快才响）。
**文件只在浏览器本地解码，不会上传到任何服务器**，刷新页面即恢复默认。

## 本地运行

纯静态页面，但 `assets/spin.mp3` 是用 `fetch` 加载的，
双击 `index.html` 走 `file://` 会被浏览器拦截，需要起个本地服务：

```bash
cd earth
python -m http.server 8200
# 打开 http://127.0.0.1:8200/index.html
```

## 构建

源码在 `src/`，贴图以 base64 内嵌进单文件 bundle，由 esbuild 打包：

```bash
cd earth
node build.mjs        # 产出 dist/app.js（约 11.6MB）
```
